# Metric governance and change control

> CMS synthetic claims - not real patient or provider performance.

## Single source

`config/metric_dictionary.yml` is the canonical KPI contract. Every KPI has an ID, a version, a business question, an owner role, a grain, a source model, a calculation, numerator, denominator, inclusions, exclusions, valid dimensions, time basis, refresh expectation, quality checks and known limits. These representations are generated from it and must not be edited by hand:

| Representation | Generated by |
|---|---|
| `docs/metric_dictionary.md` | `medicare-claims reports` |
| Excel `Metric_Dictionary` sheet | `medicare-claims excel` |
| Tableau field dictionary, `tableau/expected_kpis.csv`, Data Quality & Definitions page | `medicare-claims tableau` |
| Offline dashboard definitions page | `medicare-claims dashboard` |

## Changing a metric

1. Open a pull request that edits the SQL in `sql/` and the contract entry together, and increases the entry's `version`.
2. Regenerate the dbt models (`uv run python scripts/gen_dbt_models.py`). `tests/test_dbt_project.py` fails if they are stale.
3. Rederive any affected fixture value by hand in `tests/fixtures/README.md` and `expected_kpis.json` before running the pipeline. Never copy a value from pipeline output into an expected value.
4. If the KPI is recomputed by `validation.py`, change the independent pandas logic to the new definition separately.
5. Run `make fixture-all` and `make all`. These fail when a change breaks them: fixture KPI tests, SQL reconciliation, dbt tests and legacy equivalence, independent recomputation, the Excel reconciliation sheet, the Tableau Hyper tie-out and the README drift check.
6. Rebuilt artifacts: the marts, `exports/`, the Excel workbook and PDF, `tableau/data`, the packaged `.twbx`, `reports/` and the README generated blocks.
7. Approval: the metric's owner role in the contract approves the definition; the data owner approves any change to a quality check or reconciliation tolerance.

## Rules

- Payment metrics keep the CMS field names and are never called "cost". A test fails on the word "cost" in a payment metric definition or a Tableau label, unless the text says it is not cost.
- Proxy measures are labeled as proxies, and nothing is described as HEDIS, CMS-HCC or a clinical outcome measure.
- A denominator of zero gives an empty value, not zero (for example, a year with no eligible index stays has no readmission rate).
